#  2. transformers -> ==5.15.0  (lock resolves 5.16.1)

#     5.15.0 is the only version satisfying all three, and is the minimum
#     providing transformers.models.granite_swa that hf-adapters requires.
#  3. tokenizers -> ==0.22.2  (lock resolves 0.23.2)

#     hf-adapters-spyre declares `accelerate` unconditionally and unversioned, but
#     it is installed --no-deps (Step 3), so pip never fetched it. It is absent from
#     spyre-inference's lock because the vLLM path never uses it -- only the
#     hf-adapters path does, via device_map. transformers 5.15.0 raises
#       ValueError: Using a `device_map` ... requires `accelerate`
#     from AutoSpyreModelForCausalLM.from_pretrained without it. Measured
#     2026-09-28: `pip check` does NOT catch this (it reports version conflicts,
#     not absent unversioned deps), so the only thing that surfaces it is actually
#     running run_granite_spyre.py. 1.15.0 pulls in nothing new -- all seven of its

#     are already pinned here at satisfying versions.
